# 经营归因分析系统 · ui.md

## 0. 设计基线
- 技术：Vue 3 + TypeScript + Vite + Element Plus + ECharts；所有页面使用统一 `AppLayout`。
- 主色 `#4F46E5`；中性色沿用 Element Plus；语义色 成功 `#16A34A` / 警告 `#F59E0B` / 危险 `#DC2626` / 信息 `#2563EB`。
- 字体：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`；正文 14px/22px，标题 16/20/24px；间距为 8px 倍数；卡片圆角 8px，浅阴影。
- 必须覆盖四种状态：加载（骨架屏）、空态（说明+引导操作）、错误（原因+重试）、无权限；支持浅色/深色（CSS 变量）。
- 响应式：≥1280px 桌面为主；768~1279px 侧栏折叠；<768px 单栏堆叠（聊天类页面需可用）。
- 可访问性：对比度 ≥ 4.5:1；全部可交互元素可键盘操作并有可见焦点；图表提供数据表格替代视图。
- 数据密集型界面：表格与图表使用 12~13px 紧凑模式；金额千分位、变动值用 ▲红(上升)/▼绿(下降) 或按指标好坏语义着色，并同时用符号区分以避免仅靠颜色。

## 1. 页面清单
`指标异动大盘` ｜ `归因分析工作台`（核心） ｜ `业务事件日历` ｜ `指标字典配置` ｜ `报告归档与导出预览`。顶部全局栏：业务线/指标域切换、全局搜索、角色头像菜单。

## 2. 指标异动大盘
- 指标卡网格（核心经营指标）：当前值、环比/同比、迷你趋势；**异常指标**显示红色角标"异常 ▼-12.4%"，卡片边框高亮。
- 异常阈值可在卡片上快速查看（如日环比跌幅 > 8%）。
- 每张异常卡底部主按钮 `智能归因分析`，点击创建会话并跳转工作台，自动带入指标与时间范围。
- 右侧"待关注"列表按异常程度排序；时间范围、基期（同比/环比/目标）切换器。

## 3. 归因分析工作台（左中右三栏，弹性布局）
**左栏 · 会话与指标导航（240px，可折叠）**：新建分析按钮；历史会话列表（标题、目标指标、状态点）；当前目标指标概览卡（基期值/现期值/差异额/差异率）。

**中栏 · 对话与探索（自适应）**
- 自然语言输入 + 快捷追问胶囊（"按渠道下钻""排除大促影响""为什么转化率下降"）。
- 流式展示分析路径：以**步骤时间线**呈现 `识别异动 → 指标拆解 → 维度下钻 → 假设生成 → 统计检验 → 业务归因 → 策略建议`，当前步骤高亮、已完成打勾。
- **假设卡片流**：每张含假设陈述、状态（验证中/成立/已排除）、置信度条、p 值与效应量；可展开查看**沙箱代码**（只读高亮）与执行输出、耗时。
- 工具调用状态行："正在执行 SQL…""正在做 LMDI 分解…"。支持"停止分析"。

**右栏 · 动态归因看板（≥420px，可拖拽调宽，可全屏）**，页签：
1. `贡献瀑布图`：起点基期值→各因子贡献→终点现期值，正/负贡献配色+符号，悬浮显示贡献值与占比，**总和守恒校验徽标**；
2. `杜邦拆解树`：指标树节点显示数值与变动，点击节点下钻；
3. `下钻透视表`：多维层级折叠、列头排序、差额条件染色、导出当前表格；
4. `结论与证据`：核心归因结论卡片（首要/次要/内外部）+ 因果证据链（事件标签如"618 大促"）；
5. `行动项`：动作、责任岗位、预期周期、预期挽回金额；
6. `What-If`：驱动因子滑块（带当前值/建议范围）、敏感度曲线实时重算、情景 A/B/C 对比（并列柱+区间带）。
- 看板底部：`保存快照`、`生成报告`、`导出`。

## 4. 业务事件日历页
- 视图切换：时间线 / 月历；筛选：指标域、事件类型（大促/故障/政策/竞品/宏观）。
- 事件卡显示起止、影响范围（品类/渠道标签）、备注；新建/编辑抽屉（表单校验：结束≥开始）。
- 与指标趋势叠加预览：选择指标后，在迷你趋势图上标注事件区间。

## 5. 指标字典配置页
- 左：指标树（可拖拽调整层级）；右：指标详情（名称、类型、单位、模型、**公式编辑器**）。
- 公式编辑器：支持 `+ − × ÷` 与引用选择器，保存时校验循环依赖与单位一致性，右侧实时预览拆解结构。

## 6. 报告归档与导出预览
- 左侧报告列表（版本、状态、更新时间）；中间整篇排版预览（A4 宽度）；右侧批注栏（选中文本添加批注、@同事）。
- 顶部：`导出 PDF / Excel / Markdown`，导出前显示包含内容清单（可勾选章节）。

## 7. 组件清单
`MetricCard`、`StepTimeline`、`HypothesisCard`、`CodeViewer`、`WaterfallChart`、`DupontTree`、`PivotTable`、`SankeyChart`、`WhatIfPanel`、`ScenarioCompare`、`EventTimeline`、`FormulaEditor`、`ReportPreview`。

## 8. 关键交互与状态
- 三栏折叠状态与宽度持久化；刷新后恢复会话与**任务断点**（运行中的分析显示"已恢复，继续执行"）。
- 追问时看板即时标注"已刷新"并高亮发生变化的数值；切片条件以面包屑展示（如 `渠道=信息流 > 品类=美妆`），可逐级回退。
- 图表空态/错误态：数据不足时说明原因而非空白；沙箱超时展示"已终止，结果可能不完整"。
- 所有数值均可点击"查看口径/SQL"。
